# Regole per la Gestione dei Contenuti

## Architettura del Progetto

### Struttura dei Contenuti
- I contenuti statici sono gestiti in file JSON
- Separazione tra contenuto e codice
- Struttura gerarchica dei contenuti
- Percorso base: `/laravel/config/local/saluteora/database/content/pages/`

### Formato dei File
- Utilizzo di JSON per i contenuti statici
- Struttura gerarchica dei blocchi
- Supporto per contenuti multilingua
- Versionamento dei contenuti

## Processo di Modifica

### 1. Identificazione
- Verificare il percorso corretto del file JSON
- Controllare la struttura esistente
- Analizzare i blocchi disponibili

### 2. Modifica
- Utilizzare blocchi esistenti quando possibile
- Creare nuovi blocchi solo se necessario
- Mantenere la coerenza della struttura
- Seguire il formato JSON corretto

### 3. Validazione
- Verificare la sintassi JSON
- Controllare la struttura dei blocchi
- Validare i contenuti multilingua
- Testare la visualizzazione

## Best Practices

### 1. Struttura
- Mantenere la gerarchia dei contenuti
- Utilizzare blocchi riutilizzabili
- Documentare la struttura dei blocchi
- Mantenere la coerenza

### 2. Contenuti
- Separare contenuto e presentazione
- Utilizzare formattazione appropriata
- Mantenere la coerenza del tono
- Verificare le traduzioni

### 3. Versionamento
- Mantenere traccia delle modifiche
- Documentare le versioni
- Creare backup prima delle modifiche
- Testare le modifiche

## Esempi Pratici

### Modifica Homepage
1. Verificare il file `1.json`
2. Analizzare i blocchi esistenti
3. Modificare o creare blocchi
4. Validare la struttura
5. Testare la visualizzazione

2. Creare nuovi blocchi se necessario
