# Moduli Core SaluteOra

## Core Module
Il modulo core fornisce le funzionalità base del sistema:
- Gestione multi-tenant
- Sistema di autenticazione
- Gestione ruoli e permessi
- Configurazione base
- Logging e monitoraggio

## Patient Module
Gestisce i dati dei pazienti:
- Anagrafica completa
- Calcolo ISEE
- Storico visite
- Documenti clinici
- Notifiche e promemoria

## Dental Module
Gestisce le attività odontoiatriche:
- Appuntamenti
- Visite
- Trattamenti
- Piano terapeutico
- Documenti clinici

## Reporting Module
Gestisce la reportistica:
- Dashboard statistiche
- Report personalizzati
- Export dati
- Grafici e analisi
- KPI monitoraggio

## UI Module
Gestisce l'interfaccia utente:
- Componenti riutilizzabili
- Tema personalizzato
- Responsive design
- Dark/light mode
- Accessibilità

## User Module
Gestisce gli utenti del sistema:
- Gestione profili
- Ruoli e permessi
- Audit log
- Preferenze utente
- Notifiche

## Tenant Module
Gestisce il multi-tenant:
- Configurazione tenant
- Isolamento dati
- Personalizzazione
- Gestione risorse
- Backup tenant
