# Documentazione del Progetto SaluteOra

## Panoramica
Il progetto "Promozione della salute orale per le gestanti in condizioni di vulnerabilità socio-economica" è un'iniziativa coordinata dall'INMP, con la collaborazione della Fondazione ETS e altri enti del terzo settore.

## Obiettivi del Progetto
- Migliorare la salute orale delle gestanti con ISEE inferiore a 20.000 euro
- Fornire visite odontoiatriche e sessioni di igiene orale
- Educare le pazienti sulle pratiche di cura dentale a casa
- Integrare servizi odontoiatrici con servizi sociali e di assistenza alla gravidanza
